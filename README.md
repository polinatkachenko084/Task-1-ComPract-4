# Task-1-ComPract-4
Завдання
Обчислити значення квадратного кореня із числа a > 0 із заданою точністю e на основі рекурентного співвідношення:
x(n+1) = 1/2 · ( x(n) + a / x(n) ),    x(0) = a / 2
де x(n) — попереднє, x(n+1) — наступне наближення до кореня. Точність вважається досягнутою, коли |x(n+1) − x(n)| < 10⁻⁵.
